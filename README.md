# NASA Space Physics Research Intelligence

Advanced local-first scientific RAG built with **LangChain**, **Ollama/Qwen**, **Qdrant**, hybrid dense + BM25 retrieval, local cross-encoder reranking, source citations, FastAPI, Streamlit, MCP and Promptfoo.

## Included documents
Add research PDFs you are permitted to use to `data/raw/`. PDF files, local indexes, and uploaded data are excluded from Git, so provide and index your own corpus after cloning. The baseline indexes extractable PDF text page-by-page. Scanned pages, figures, tables and complex equations may need OCR/layout-aware processing; this project does not claim complete multimodal understanding yet.

## Pipeline
1. PyMuPDF extracts text and page metadata.
2. LangChain text splitter creates overlapping chunks.
3. Sentence Transformers creates local embeddings.
4. Qdrant stores vectors and metadata.
5. BM25 provides lexical retrieval.
6. LangChain EnsembleRetriever combines dense and sparse search using weighted reciprocal-rank fusion.
7. CrossEncoder reranks candidates.
8. ChatOllama/Qwen answers from evidence with filename/page citations.
9. Streamlit and FastAPI expose the application.
10. MCP exposes research QA and evidence search.
11. Promptfoo and custom Python metrics support regression testing.

## Windows setup
Use Python 3.11.

```powershell
py -3.11 -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
ollama pull qwen3:8b
ollama serve
```

For OCR of scanned PDFs, install the Tesseract OCR executable separately and
make sure it is available on `PATH`. The `pytesseract` Python package is
installed by `requirements.txt`.

In another terminal:

```powershell
.\\.venv\\Scripts\\Activate.ps1
python ingest.py
streamlit run app.py
```

## CI
GitHub Actions runs the test suite on pushes and pull requests to `main`. It installs `requirements.txt` on Python 3.11 and runs `pytest -q`.

This repository setup publishes source code and verifies it in CI; it does not provision a hosted app or a remote Ollama model service. The app expects an Ollama endpoint, Qdrant Cloud credentials, and an indexed corpus. PDF files and the BM25 index remain local.

API alternative:

```powershell
uvicorn api:app --reload
```

API docs: http://localhost:8000/docs

## MCP
Run `python mcp_server.py` from the project root using the project's virtual environment. Configure your MCP-compatible client to launch this command.

## Promptfoo
Start the API, then run:

```powershell
npx promptfoo eval -c evaluation/promptfoo.yaml
```

The included evaluation cases are starter tests, not a validated benchmark. Add human-reviewed expected passages and page-level labels before publishing metric scores.

## Configuration
Edit `.env`. Default embedding model is `BAAI/bge-small-en-v1.5` for lower resource use. For stronger embeddings, try `BAAI/bge-m3`. Default reranker is `cross-encoder/ms-marco-MiniLM-L-6-v2`; a larger BGE reranker can be configured if memory allows.

## GPU / RAM
The default embedding and reranker device is CUDA. If CUDA is unavailable, change `device="cuda"` to `device="cpu"` in `retrieval/index.py` and `retrieval/rerank.py`. On a 16 GB RAM machine, start with Qwen3 8B quantized, modest context length, and the compact embedding/reranker models. Actual performance depends on GPU VRAM.

## Engineering limitations and safety
- First run downloads Hugging Face model weights. After caching, inference can run locally. For air-gapped use, pre-download model files and configure local paths.
- Qdrant vectors are stored in Qdrant Cloud. Set both `QDRANT_CLUSTER_ENDPOINT` and `QDRANT_API_KEY` in `.env`; keep the API key private and out of version control. The BM25 index remains local.
- BM25 is pickled; only load files generated by this application. Never load untrusted pickle files.
- PyMuPDF extraction may not preserve two-column order, tables, equations or figure context perfectly. Add Docling/OCR and figure-caption association as an extension.
- LLM-generated citations are not guaranteed correct. Validate each citation against source pages. Treat outputs as research assistance, not an authoritative scientific publication.
- Do not claim evaluation scores until tests have been run against a human-verified gold set.
